# GeoAI Portfolio

面向 GIS、遥感、数据、产品与数字化岗位的个人项目作品集，展示科研和工程项目中的问题拆解、数据流程、系统设计、实现与验证边界。

## 作者

唐皓宇，中国科学院大学资源与环境硕士研究生（2027 届，在读）；本科毕业于郑州大学地理信息科学专业。

## 项目

- [CWC](projects/CWC.html)：全球尺度冠层水分研究与建模。
- [LFMC](projects/LFMC.html)：多源遥感活体植被含水率建模与区域产品。
- [WebGIS](projects/WebGIS.html)：面向旅游场景的空间信息应用原型。
- [ProjectGame](projects/ProjectGame.html)：Godot 六边形战棋独立原型。
- [ProjectGame2](projects/ProjectGame2.html)：卡牌驱动的规则型世界模拟原型。

项目周期以各详情页为准，项目当前状态和验证范围均按已记录事实说明。

## 技术关键词

Python、LightGBM、PyTorch、遥感与栅格数据处理、GeoTIFF、Vue、MapLibre、FastAPI、PostGIS、Godot、GDScript，以及离线规则型资料处理工具。具体技术用途和项目边界见详情页。

## 静态部署

网站使用原生 HTML 与 CSS，无构建步骤、服务器后端、外部 CDN 或第三方脚本。将本仓库静态文件发布到 GitHub Pages 的根目录即可；完成仓库创建后，在 GitHub Pages 设置中选择从分支根目录部署。

## 图片与素材归属

本次发布版暂不包含项目图片。已有记录能够确认 CWC/LFMC 图件来源和验证口径，但不足以证明底层数据及图件具备公开传播许可，因此没有将其纳入网站。WebGIS 截图涉及第三方底图和演示 POI；ProjectGame 与 ProjectGame2 截图涉及待核实的美术资源许可，也未纳入。许可核实完成后，方可另行加入相应图片。
