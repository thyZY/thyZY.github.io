项目简介

ProjectGame2 是与 ProjectGame 完全独立的 Godot 4.6.3 2D 世界建造和模拟原型。玩家看 18 张队列卡，从前三张候选挑选地块，在已探索区域按邻接与地块规则放置；世界随后按 tick 更新。项目从 V0.1 的卡牌地图逐步扩展到 V1.2 的政治分离与内战闭环。

背景问题

产品设计需要让“造地”具有规划选择，也要让放置失败不破坏世界。世界系统增多后，聚落、国家、关系、战争与存档需共享一致的权威状态；稀有政治事件既要可重放验收，也不能被测试画面误称为普通自然生成结果。

解决方案

卡牌队列只允许前三张直接放置，同时提供重排和丢弃。放置服务先校验目标揭露、邻接和地块阶段，再提交地图变更和补牌。GameState 按完整 tick 协调聚落、国家、外交、治理、分离和战争服务；随机流按系统隔离以支持确定性测试。V1.2 的分离压力、临时国家、内战与结局采用规则和 JSON 配置，不依赖大语言模型自主决策。

技术架构

唯一的产品场景 scenes/main.tscn 以 Main 控件为入口；scripts/main.gd 在运行时装配地图渲染、CardBar 与多个信息面板。scripts/core/game_state.gd 协调事件，world_model.gd 保存权威格状态，hex_math.gd 处理轴向坐标和距离，placement_service.gd 决定合法性，simulation/ 下的服务处理世界阶段。save_service.gd 支持版本化快照与旧 schema 向 1.2 的迁移。

V1.2 的 QA 报告结论为 ACCEPTED，但没有相应 Git tag，验收清单还留有未勾选项。服务调用面宽与长期随机事件覆盖率是当前架构的实际限制。

核心功能

  • 18 张地块卡队列、前三张可放、重排/丢弃与六边形放置校验。
  • 生产、居民/聚落成长与国家形成的规则型世界模拟。
  • 种族、文化、外交、战争、占领、治理、分离运动及内战的分阶段状态。
  • 地图覆盖层、聚落/国家/军队信息面板、消息与编年史。
  • 版本化存档、恢复和 V1.0/V1.1 到 V1.2 的数据迁移。

AI / 智能化能力体现

卡牌放置后，世界按 tick 通过代码规则推进聚落、国家、外交、战争和分离状态；随机流隔离支持确定性复现。自主文明是规则与状态模拟，不是 LLM、RAG 或生成式 AI 智能体。AI Coding 仅作为开发辅助工具。
